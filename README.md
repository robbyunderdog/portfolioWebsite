# Portfolio Website - robbywarner.com
Source code for my personal portfolio website, built with [Astro](https://astro.build).

## Development
```
npm install
npm run dev      # local dev server with live reload at http://localhost:4321
npm run build    # production build to ./dist
npm run preview  # preview the production build
```

The previous hand-written HTML/CSS/JS version is preserved under the `old-site` git tag.
